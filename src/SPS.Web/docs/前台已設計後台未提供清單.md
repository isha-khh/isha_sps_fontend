## 四、會員中心（2026-10-06 全部完成）

`MemberCenterContent` 的九個項目都已經接上真資料：基本資料、變更密碼、Passkey 管理、權益升級、公司資料、成員管理、產品相關資訊、媒合資料維護、我的最愛。授權一律用「只能操作自己的資料」的獨立端點（`/api/member/*`，身分取自 token 的 `MemberId`，成員管理另外限制同公司且要有編輯公司資料權限）。

還沒做的延伸：同公司同事刊登的需求在「媒合資料維護」看不到（目前只看自己送出的）、逐項的產品目錄（`Product` 仍只有後台可管理）、Passkey 需要在正式環境用真實裝置驗證。
