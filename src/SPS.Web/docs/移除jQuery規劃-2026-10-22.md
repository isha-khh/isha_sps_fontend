# 移除 jQuery 規劃（2026-10-22）

目標：前台（`src/SPS.Web`）不再載入 jQuery 與依賴它的舊站套件，改由 React 元件／原生 JS 處理。

## 為什麼要換

舊站腳本多半是「頁面載入時（`$(document).ready`）對當下存在的元素綁一次事件」。前台已大量改用 `next/link` 做客戶端導覽，
導覽後才渲染出來的元素不會被綁到，造成「重新整理才會動」的問題（例如手機版「顯示分類」按鈕，已改 React state 修掉）。

## 現況盤點（2026-10-22，以 layout.tsx 載入的腳本與實際頁面元素查證）

| 項目 | 是否依賴 jQuery | 備註 |
|---|---|---|
| Bootstrap 5.3 | 否 | 保留 |
| AOS、Fancybox 5、TweenLite／CSSPlugin | 否 | 保留 |
| **slick 輪播** | 是（jQuery 外掛） | `Carousel.tsx`、`CarouselControls.tsx`、`HomeVideo`、`HomeService`、`PromoBanner` 使用；首頁實測有 6 個 `.slick-slider` |
| **bsnav 主選單** | 是 | `Headers.tsx` 的 useEffect 直接用 `window.jQuery` 接管手機選單開關／ESC／焦點鎖定；`.bsnav-mobile`、`.bsnavclose` 的樣式吃 bsnav 的 class |
| **coreScript.js** | 是 | 296 行，見下表 |

### coreScript.js 逐項

| 功能 | 實際頁面是否存在對應元素 | 處理 |
|---|---|---|
| 頁首固定高度補償（`.banner-top`、`.top_marquee`） | 否（0 個） | 刪除（階段一） |
| 回頂端（`.footer .gotop`、`.floating_circle`） | 否 | 刪除（階段一） |
| 側欄收合（`.collapse-side-btn`、`.collapsed-btn`） | 已由 `CategorySidebar` 的 React state 取代 | 刪除（階段一） |
| 日期選擇器 `[data-datepicker]` | 否，且 datepicker 外掛本來就沒載入 | 刪除（階段一） |
| `shareTo`、`resetOption`、`tooltipUpdate`、`mobilecheck` | 沒有任何地方呼叫（`ShareBox` 有自己的實作） | 刪除（階段一） |
| `is_scroll`（捲動超過 10px 加到 body） | 是（頁首縮小的樣式用） | 改原生 JS（階段一） |
| AOS 初始化／refresh | 是（9 個 `[data-aos]`） | 改原生 JS（階段一） |
| Fancybox 全域綁定 | 是（8 個 `[data-fancybox]`） | 改原生 JS，並改為「無條件綁定」（原本載入當下頁面有 `[data-fancybox]` 才綁，從沒有燈箱的頁面導覽過去會失效）（階段一） |
| 無障礙 Tab／Alt 快捷鍵 | 是 | 本來就是原生 JS，保留 |
| `.navbar-toggler` 點擊（手機主選單） | 是 | 隨 bsnav 一起處理（階段二） |

## 階段

1. **coreScript.js 去 jQuery**（只剩手機主選單那一段）：刪死碼、`is_scroll`／AOS／Fancybox 改原生。風險低。
2. **手機主選單改 React**：`Headers.tsx` 用 React state（或 Bootstrap Offcanvas）處理開關、ESC、Tab 焦點鎖定；
   拿掉 bsnav.min.js；保留 `.bsnav-mobile`、`.bsnavclose` 等 class 讓既有 CSS 繼續有效。要逐項實測手機／桌面。
3. **輪播換掉 slick**：換成不依賴 jQuery 的套件（Embla／Swiper）或自己用 CSS scroll-snap 寫，
   `Carousel.tsx` 對外介面盡量不變；要對 `.slick-dots`、箭頭等設計稿樣式重新對一次。最大也最顯眼，最後做。
4. **收尾**：`layout.tsx` 移除 jQuery、slick、bsnav、coreScript.js 的載入與 `legacy-globals.d.ts` 的對應宣告，
   清掉 `public/js` 內不再使用的檔案與註解裡的舊說明。

每階段獨立一個 commit，部署測試機實測後再進下一階段。

## 驗收重點（每階段都要測）

- 首頁輪播（服務、影音、企業、橫幅）自動播放、箭頭、圓點、暫停鈕。
- 手機主選單開關、遮罩點擊、ESC、Tab 焦點鎖定；桌機下拉選單。
- 從別的頁面用連結導覽進首頁／有燈箱的頁面後，輪播與燈箱仍能動。
- 影音專區、產業案例點圖放大（Fancybox）。
- 捲動後頁首縮小（`is_scroll`）、AOS 進場動畫。
